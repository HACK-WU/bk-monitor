## 优化复查（v4）

> 复查时间：2026-06-15
> 复查对象：`data-flow-model.md` v4（新增异步刷新 Token）
> 触发原因：用户要求添加异步刷新 token 功能

### 优化内容

| # | 优化项 | 优化前 | 优化后 |
|---|--------|--------|--------|
| 1 | refresh_token 字段 | 一期不存 | 存储，用于异步刷新 |
| 2 | 异步刷新数据流 | 无 | 新增 4.6 异步刷新 Token（用户访问时触发） |
| 3 | 防重复刷新策略 | 无 | 通过 updated_at 判断，间隔 >= 5 分钟 |
| 4 | 刷新失败处理 | 无 | 保留原 token，返回当前 token 仍可使用 |

### 关键设计决策

| 项目 | 方案 | 理由 |
|------|------|------|
| refresh_token 存储 | ✅ 存储 | 异步刷新需要调用 TAPD 刷新接口，必须有 refresh_token |
| 防重复刷新 | 用 updated_at 判断 | 减少字段，简化模型 |
| 刷新失败处理 | 保留原 token | 刷新失败原因多样，保留 token 可用于重试 |
| 刷新频率 | 用户访问时触发 | 利用用户访问时机，避免额外定时任务 |
| 提前刷新量 | 过期前 30 分钟 | 避免用户感知中断 |

### 复查结论

- **总质疑数**：0
- **文档状态**：✅ 可进入 design-craft
